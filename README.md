# 🧊 Sobre a Tokito Bot V10

A **Tokito Bot V10** é uma base para WhatsApp desenvolvida com foco em facilidade de uso, personalização, organização e diversos sistemas prontos.

A ideia do projeto é permitir que qualquer pessoa consiga baixar, configurar e utilizar o bot de forma simples.

Você pode modificar o projeto conforme sua preferência:

- Alterar o nome do bot
- Alterar o nome do dono
- Alterar o número do dono
- Alterar o prefixo
- Personalizar mensagens
- Adicionar novos comandos
- Remover comandos
- Criar novos sistemas
- Alterar menus
- Personalizar o visual
- Utilizar o nome Tokito, se desejar

Apenas respeite as regras do projeto.

# ⚠️ AVISO MUITO IMPORTANTE

> [!CAUTION]
> ## NÃO USE `npm install`
>
> A **Tokito Bot V10 já acompanha o `node_modules` completo**.
>
> Isso acontece porque a base utiliza uma **versão modificada da Baileys**, necessária para algumas funções especiais do bot.
>
> Se você executar:
>
> ```bash
> npm install
> ```
>
> algumas dependências podem ser reinstaladas ou substituídas.
>
> Isso pode fazer com que a **Baileys modificada seja substituída pela versão original**, removendo modificações importantes da Tokito V10.

### ❌ Não execute:

```bash
npm install
```

Também evite executar sem necessidade:

```bash
npm update
```

```bash
npm audit fix
```

ou qualquer outro comando que reinstale automaticamente as dependências.

> [!IMPORTANT]
> Se você baixou a Tokito Bot V10 completa, **não precisa instalar as dependências novamente**.
>
> O `node_modules` necessário já acompanha o projeto.

# 📥 Como baixar

Você pode baixar a Tokito Bot V10 diretamente pelo GitHub.

Também é possível clonar o repositório utilizando Git:

```bash
git clone https://github.com/dylan-Modz/Tokitobot-V10.git
```

Depois entre na pasta:

```bash
cd Tokitobot-V10
```

> [!WARNING]
> Depois de baixar ou clonar o projeto, **não execute `npm install`**.

---

# 🚀 Como iniciar o bot

Depois de baixar a base completa, entre na pasta:

```bash
cd Tokitobot-V10
```

E inicie normalmente:

```bash
npm start
```

Pronto.

O painel da Tokito V10 será aberto automaticamente no terminal.

# 📦 Por que o `node_modules` está no GitHub?

Normalmente projetos Node.js não enviam o `node_modules` para o GitHub.

Porém, na Tokito Bot V10 existe um motivo específico.

A base utiliza uma **Baileys modificada**.

Essas modificações são importantes para determinadas funções utilizadas pelo projeto.

Por isso, a distribuição oficial acompanha as dependências necessárias.

> [!WARNING]
> Substituir o `node_modules` ou reinstalar a Baileys pode fazer algumas funções deixarem de funcionar.

---

# ❌ Não faça isso

Não execute:

```bash
rm -rf node_modules
```

e depois:

```bash
npm install
```

Isso poderá substituir a estrutura utilizada pela versão oficial da Tokito.

Também não substitua a Baileys modificada por outra versão sem saber quais recursos dependem dela.

---
