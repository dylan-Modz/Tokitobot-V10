# 🧊 Sobre a Tokito Bot V10

A **Tokito Bot V10** é uma base para WhatsApp desenvolvida com foco em facilidade de uso, organização e personalização.

O projeto é disponibilizado gratuitamente para a comunidade e pode ser modificado conforme sua preferência.

Você pode alterar nome, prefixo, mensagens, menus, comandos, sistemas e outras partes da base.

---

# 📱 Instalação no Termux

Primeiro atualize o Termux:

```bash
pkg update -y && pkg upgrade -y
```

Instale as dependências necessárias:

```bash
pkg install nodejs git ffmpeg -y
```

Depois clone o projeto:

```bash
git clone https://github.com/dylan-Modz/Tokitobot-V10.git
```

Entre na pasta:

```bash
cd Tokitobot-V10
```

Instale os módulos:

```bash
npm install
```

E inicie:

```bash
npm start
```

---

# ⚠️ Usando a base no /sdcard

Caso a Tokito esteja dentro do armazenamento interno do Android, como:

```text
/sdcard/Tokitobot-V10
```

use:

```bash
npm install --no-bin-links
```

Isso evita erros de permissão relacionados à criação de links dentro do `node_modules`.

Depois inicie normalmente:

```bash
npm start
```

---

# 🖥️ VPS / Linux

Instale o Node.js, Git e FFmpeg.

Depois:

```bash
git clone https://github.com/dylan-Modz/Tokitobot-V10.git
cd Tokitobot-V10
npm install
npm start
```

---

# ♻️ Atualização

Para iniciar normalmente:

```bash
npm start
```

Para atualizar a Tokito pelo terminal:

```bash
npm start up
```

O sistema de atualização também pode ser utilizado diretamente pelo bot.
